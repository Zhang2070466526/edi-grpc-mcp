# 射频链路灵敏度与动态范围计算说明

根据链路噪声系数、输入 1dB 压缩点、等效噪声带宽和最低所需信噪比，计算输入等效噪声底、最低输入灵敏度、压缩受限动态范围，并可对目标动态范围做达标评价。

对应 MCP 工具 `calculate_rf_dynamic_range`（`servers/rf_analysis/rf_dynamic_range.py`）。

## 输入（对应 RfInput）

| 字段 | 类型 | 单位 | 约束 |
|---|---|---|---|
| `noise_figure_db` | double | dB | 有限数，**≥0** |
| `input_p1dbm` | double | dBm | 有限数，可为负 |
| `bandwidth` | double | — | 等效噪声带宽数值，**>0** |
| `bandwidth_unit` | enum | — | `hz`/`khz`/`mhz`/`ghz`，调用前统一换算 |
| `required_snr_db` | double | dB | 有限数，可为负；为 0 时灵敏度=噪声底 |

## 输出（对应 RfResult）

| 字段 | 单位 | 公式 |
|---|---|---|
| `noise_floor_dbm` | dBm | `−174 + 10·log10(BW_Hz) + NF` |
| `sensitivity_dbm` | dBm | `noise_floor_dbm + required_snr_db` |
| `dynamic_range_db` | dB | `input_p1dbm − sensitivity_dbm` |

## 目标动态范围评价（对应 TargetEvaluation）

| 字段 | 单位 | 公式 / 含义 |
|---|---|---|
| `meets_target` | — | `margin_db ≥ 0` |
| `margin_db` | dB | `dynamic_range_db − target_dynamic_range_db` |
| `required_sensitivity_dbm` | dBm | `input_p1dbm − target_dynamic_range_db`（P1dB 不变时，达到目标所需的灵敏度上限） |

## 注意事项

1. `bandwidth` 换算成 Hz 后参与 `10·log10`，`bandwidth_unit` 只是换算系数（`hz=1`、`khz=1e3`、`mhz=1e6`、`ghz=1e9`）。
2. 热噪声密度取 `−174 dBm/Hz`（室温 290K）。
3. 所有输入要求有限数，否则报参数错误；`noise_figure_db < 0`、`bandwidth ≤ 0` 也报错。
