# 仿真器件工具说明

> 本文档说明 EDI 的「仿真器件」相关工具的**数据源、功能、为什么需要**，帮助选对工具。
> 涉及 12 个工具：10 个在 `servers/eda/simulation_components.py`，2 个查询工具在 `servers/eda/project_manage.py`。

## 一、数据源总览（核心区分）

这批工具按「数据从哪来」分两类：

| 数据源 | 工具 | 特点 |
|---|---|---|
| **本地磁盘读**（读已保存的 `.epp` / 参数目录，EDI 不启动也能用） | `get_simulation_component_schema` | 读的是**落盘状态**，EDI 未保存的改动不反映 |
| **gRPC 实时**（走 EDI 服务，需 EDI 在线） | 其余 10 个 | 操作 **EDI 内存态**，改完要在 EDI 里保存才落盘 |

关键原则：**「看器件有哪些参数、内部叫什么名」用磁盘读；「实时操作 EDI 里的器件」用 gRPC。**

---

## 二、逐个工具说明

### 查询 / 只读

#### `get_simulation_component_schema`（磁盘读）

- **功能**：查某器件类型（SP / HB / XDB）的参数 Schema 和权限（哪些参数可写）。
- **数据源**：`simulation_component_catalog.json`（本地参数目录 v2.0）。
- **为什么需要**：更新/创建器件前先查「这个类型有哪些参数、哪些允许改」，配合 `update_simulation_component` 做参数校验。

#### `list_schematic_components`（gRPC，在 `project_manage.py`）

- **功能**：gRPC 实时查原理图全部器件（含完整参数）。
- **数据源**：EDI 内存态（`LIST_SCHEMATIC_COMPONENTS`）。
- **为什么需要**：要看 EDI **当前实时**打开/修改的状态（未保存也看得到）。

#### `get_schematic_component_info`（gRPC，在 `project_manage.py`）

- **功能**：按实例名查器件参数与几何信息（可传列表）。
- **数据源**：EDI 内存态（`GET_SCHEMATIC_COMPONENT_INFO`）。
- **为什么需要**：只关心某一个器件时，不用拉全量列表。

---

### 创建 / 修改 / 删除（gRPC，改 EDI 内存态）

#### `update_simulation_component`

- **功能**：按实例名更新器件参数（三路类型推断 + wire→public 校验）。
- **为什么需要**：改器件参数的**核心工具**；改之前用 `list_schematic_components` 拿到正确的参数名。

#### `delete_simulation_component`

- **功能**：按实例名删除器件及其连接线（⚠️ 不可恢复）。
- **为什么需要**：移除不要的器件。

#### `replace_port_component`

- **功能**：把端口器件替换成另一种类型（如 TermG ↔ P_nToneG）。
- **为什么需要**：改激励源类型，不用删了重建。

#### `set_component_active_state`

- **功能**：确定性设置器件状态 `NORMAL` / `DISABLED` / `SHORTED`。
- **为什么需要**：仿真时临时短路/禁用某个器件（不删、可逆）。

#### `replace_schematic_from_file`

- **功能**：从 `.ep` 文件整体替换原理图（⚠️ 整图覆盖，原内容丢失）。
- **为什么需要**：批量改原理图（比逐个删加快）。

#### `attach_out_component`

- **功能**：给器件引脚挂载 Out 器件并自动连线。
- **为什么需要**：加输出端口 / 探测点。

#### `update_schematic_components_transform`

- **功能**：批量设置器件位置 / 旋转 / 镜像（坐标按 12.5 网格吸附）。
- **为什么需要**：布局调整，不用逐个拖。

---

## 三、典型流程

1. **看器件参数（要改什么 key）** → `list_schematic_components`（gRPC 实时，含参数）
2. **查参数约束** → `get_simulation_component_schema`
3. **改参数** → `update_simulation_component`
4. **看实时状态** → `list_schematic_components` / `get_schematic_component_info`（gRPC）
5. **在 EDI 里保存** → 再 `list_schematic_components` 确认

## 四、一句话选型

- 要「实时读器件参数」→ `list_schematic_components`
- 要「查参数 Schema/权限」→ `get_simulation_component_schema`
- 要「实时看 EDI 状态」→ `list_schematic_components` / `get_schematic_component_info`
- 要「改/删器件」→ `update_simulation_component` / `delete_simulation_component`
- 要「换端口类型 / 短路禁用 / 批量布局 / 挂 Out」→ `replace_port_component` / `set_component_active_state` / `update_schematic_components_transform` / `attach_out_component`
